# House Price Prediction using Linear Regression

## Project Overview
This project predicts house prices using Machine Learning techniques and Linear Regression.

## Features
- Data Cleaning
- Missing Value Handling
- Exploratory Data Analysis (EDA)
- Correlation Analysis
- Outlier Detection
- Feature Selection
- Linear Regression Model
- Model Evaluation

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset
Kaggle House Prices Dataset

## Model Performance
- R² Score: 0.78
- MSE: 1684081420

## Visualizations
Includes:
- Correlation Heatmap
- SalePrice Distribution
- Actual vs Predicted Prices
